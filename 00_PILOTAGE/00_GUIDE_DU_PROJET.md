# Pixelmon — Les Échos du Monde — Version 23

## Rôle de ce dossier

Cette version rassemble les documents de conception et les ressources du projet. Les espaces MCreator et les exports restent à la racine pour préserver leurs chemins de travail.

Le fichier [00_LIRE_EN_PREMIER.md](../00_LIRE_EN_PREMIER.md) présente l’arborescence. Les nouveaux ajouts vont dans le document correspondant. Une décision ne doit être écrite qu’à un seul endroit ; les autres documents renvoient vers elle.

## Archives migrées

Les documents déplacés dans `../90_ARCHIVES/DOCUMENTS_MIGRES/` conservent les informations historiques. Ils restent des sources de référence jusqu’à ce que leur contenu utile soit classé dans les documents de travail. Ne pas les supprimer avant cette vérification.

## Statuts

| Statut | Signification |
|---|---|
| Validé | Décision définitive. |
| À valider | Proposition en attente de décision. |
| À définir | Information manquante. |
| À tester | Fonction à vérifier dans le modpack. |
| À faire | Élément à créer ou installer. |
| Terminé | Créé et vérifié en jeu. |
| Abandonné | Idée écartée, avec sa raison. |

## Règles de travail

- Avancer une décision ou une quête à la fois.
- Ne pas présenter une idée comme un fait avant sa validation.
- Ne pas annoncer une fonction technique sans test dans le modpack.
- Les descriptions de quêtes sont souvent les pensées de Link ; les dialogues complets viendront plus tard.
- Les quêtes principales utilisent FTB Quests. Les PNJ Pixelmon ajoutent des scènes et des combats, sans liaison automatique tant que celle-ci n’est pas testée.
- Ne pas supprimer un document migré avant d’avoir vérifié que toutes ses informations utiles sont classées dans les fichiers de travail.
