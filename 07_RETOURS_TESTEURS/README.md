# Retours des testeurs — Les Échos du Monde

Cet espace est destiné aux personnes qui testeront le prologue de **Les Échos du Monde**.

## Règles
- Ne modifiez pas les fichiers du modpack, du lore ou des quêtes.
- Utilisez uniquement cet espace pour rédiger vos retours.
- Ne supprimez pas les avis des autres testeurs.
- Indiquez votre pseudo et, si possible, la version du modpack testée.
- Les idées proposées ici ne sont pas automatiquement intégrées au projet.

## Où écrire ?
- **AVIS_QUETES.md** : retours sur les quêtes, objectifs, rythme et compréhension.
- **AVIS_LORE.md** : retours sur l'histoire, les personnages et l'univers.
- **IDEES_A_EXPLORER.md** : nouvelles idées et suggestions.
- **BUGS.md** : problèmes rencontrés pendant le test.

Merci d'avoir testé le prologue !
