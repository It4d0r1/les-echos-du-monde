# Idées à explorer

Ce dossier sert à conserver les idées drôles, étranges, ambitieuses ou incomplètes sans les confondre avec le canon.

Une idée rangée ici n'est **ni validée, ni prévue, ni promise au joueur**.

## Format d'une idée

```text
# Nom de l'idée

Statut : À explorer

Idée :
Résumé simple de l'idée.

Pourquoi elle pourrait être intéressante :
- Ce qu'elle apporte à l'histoire ou au gameplay.

Risques ou questions :
- Ce qui doit être vérifié, équilibré ou expliqué.

Liens possibles :
- Quêtes, personnages, légendaires ou lieux concernés.
```

## Après discussion

- Si l'idée est retenue, la déplacer dans le fichier de lore, de quêtes ou de technique concerné.
- Si elle est abandonnée, la laisser ici avec le statut `Abandonnée` et la raison.
