# Idées à explorer

Ce dossier recueille les idées drôles, étranges, ambitieuses ou incomplètes. Elles ne font pas partie du canon tant qu’elles ne sont pas validées.

## Format d’un fichier d’idée

```text
# Nom de l’idée

Statut : À explorer

Idée :
Résumé simple.

Pourquoi elle pourrait être intéressante :
- Apport au lore ou au gameplay.

Risques ou questions :
- Ce qui doit être vérifié ou expliqué.

Liens possibles :
- Quêtes, personnages, légendaires ou lieux concernés.
```

## Après discussion

- Si l’idée est retenue, la déplacer vers le document de lore, de quêtes ou de technique concerné.
- Si elle est abandonnée, l’ajouter au [registre des idées abandonnées](IDEES_ABANDONNEES.md), avec la raison et les éléments qui pourraient être réutilisés.
- Si une idée abandonnée est reprise plus tard, mettre à jour son entrée et indiquer où elle a été intégrée. Ne pas supprimer son historique.
